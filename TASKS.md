# Autofleet P0 + P1 checklist

Spec: `docs/AUTOFLEET_SPEC.md`. Build `dotnet build -c Release`, then JIT check
(`scratchpad\jitcheck`, args: game Bin, bin\Release\Autofleet.dll, `$env:DOTNET_ROLL_FORWARD='LatestMajor'`).

## Decisions (keep in sync with code)

- Module types are a registry (`src/Autofleet/Registry.cs`); unimplemented ones (Hunt, Support, Build, Trade, Crew, Production) are listed but never activate.
- Cargo policy (collect template, keep-all, keep-min, reserved keep-max/sell/pickup) lives in the profile only (per-ship overrides removed; old ones dropped on load).
- Collect filter (user + Codex, 2026-10-29): effective filter = the ship's vanilla `ShipMetadata.BannedResourceTypes` (shared with the game's resource window; null = all). Profile `CargoPolicy.Collect` is only a template: a toggle sends `MPSetResourceBannedInput` for the toggled types only to every commandable ship on the profile (automation on or off; other per-ship bans survive, `MinerManager.PushTemplate`); an explicit profile pick copies it once, differing types only (`CopyTemplate`); never on load/reconcile/draft, so existing bans survive an upgrade. Per-ship grid in Assignments edits that ship's bans only. Agent mask/ranks key on the ban set's content mask (`World.BannedMask`, set mutated in place), so a ban change from either UI re-plans a running harvest. Bans are read only by the owner-side planner (input applies locally at once).
- Live profiles (no revisions, schema 2): ships store `ProfileId` and read the profile live; any edit reaches them next tick (Resolver keys on `Store.LibraryVersion`). Keep-min pushed by `MinerManager.SyncKeep` (0.5 s stable, owner only, only diffs). Profile used by a running ship can't be deleted; drafts move to the default profile; unknown id = agent holds (Paused, "profile not found") until a profile is picked. Live reconcile: PlanSig has full scope, collect change stops own salvage + re-plans, escort re-issued on follow-distance change, restored owner checked against live config. Co-designed with Codex 2026-10-27 (topic autofleet-design).
- Arbitration: manual/pause > Avoidance escape > Retreat > temp intents (unload now, return home) > task modules by priority (tie: lower cost, pairwise stasis bias as before; then stable order) > idle (anchor follow / park at offload target).
- Equal priority never preempts; higher priority preempts only via its cheap trigger and after MinCommitMs.
- Persistence: profiles library `Autofleet.profiles.json`; working state `Autofleet.state.json`; per-save snapshot `Autofleet.saves\<hash>.json` (save path + mtime) with runtime provenance (own command IDs) for reconcile after load. Legacy `MiningDrone.settings.json` migrated once, never deleted.

### Co-designed with Codex (agent-link topic autofleet-design, 2026-10-27)

- D1 schema: `[JsonExtensionData] Extra` on every persisted object (base `Extensible`), copied by Clone; Choice params = stable indexes; no per-object migrators yet. Guards: module `DefVersion` newer than the registry -> blocker, module off; file `Schema` newer than `Store.SupportedSchema` -> used, never overwritten. Why: future fields round-trip, a downgrade cannot destroy or silently misrun newer data.
- D2 stuck: order reverse -> sidestep L/R -> move off body -> salvage body -> shoot body -> reverse/sidestep -> re-plan with avoidance circle -> give up target -> help status. Shooting only junk (asteroids/wrecks). "Free" = moved 300 AND no longer touching the wedging body. Why (Codex): rotationOnly attack still moves; CanBeAttackedBy alone must not license auto-fire.
- D3 stasis yield: live spawner ship -> this spawner's decoded payload -> carried ObjectID observation -> pristine doodad; undecoded or still-serializing payload = "maybe", picked only without a known-good candidate; source logged. Why (Codex): decoded is the saved state of this record, carried may be stale; a pending payload is not pristine.
- D4 cargo metric: threshold compares exactly the displayed fill = used/available cells, % rounded down (100% only when every cell is used). A hold that takes no unit (carried cargo, vanilla limits, cells preferred for other types) is a separate explicit offload trigger (`AtThreshold`), never a faked 100% (2026-10-29: "76/82 (100%)" bug).
- D4b no room below threshold (replaces the early return): searches use fitMask = collect ∩ not banned ∩ live capacity > 0 (one fitting type makes a rock eligible; freed space re-admits rocks, no exclusion list). Current rock without room -> own salvage stopped, "Нет места для `<res>`; ищем другую цель". Nothing found while a selected type has no room -> offload before anchor idle-follow, "Нет целей с помещающейся рудой". "Трюм полон: нет места под `<res>`" only at the threshold.
- D5 icons: screen space, above bounding circle, cmd_move.png rotated +PI/4 (up-right -> right, y-down), % label right of icon. Minimap keeps world-space icons.
- D7 Retreat (Codex): episode = Escape.Step arc (threats built even with Avoidance off) -> after 5 s predicted safe and a LegSafe first leg, follow home (retry when IssueFollow only held) -> back to the arc on a predicted intercept. Ends when the enemy is off radar for the resume delay (kept: the trigger is radar contact, earlier resume would oscillate). Retreat preempts Guard, Avoidance escape wins. Stuck escape keeps its recovery (emergency no longer cancels it), skips salvage/shoot, resumes the episode. Route: zones swept along velocity x Escape.Horizon (5 sampled circles), detour passes the outermost samples; ThreatVels cleared with ThreatZones. Not done: own hull radius in clearance, full-route ETA check.
- D8 Self-defence (Codex): policy module `defend` (emergency, prio 90; response Return fire | Evade, resume delay), never added to existing profiles (new starters miner/cow/builder/trader get it enabled, P2); idle while Guard is active. Return fire = MPEnqueueTargetsInput (whitelisted, changes only Weapon.ExplicitTargets) per operational weapon whose target queue holds nothing but ours; trigger = nearest enemy in sight within either side's max weapon range (filtered before the nearest pick); own target IDs tracked, persisted (RuntimeRecord.DefTargets) and removed (MPRemoveTargetsInput) after the delay, on pause/manual, module off and unassign; status suffix via StatusText, no owner/state change. Evade = shared escape episode (EscapeEpisode), only when neither Avoidance nor Retreat is on. Not done: true "attacked" trigger (needs a damage hook; PartHitArgs has no attacker), turning the hull for fixed weapons.
- D9 Hunt (Codex): movement task module (prio 75), params scope Zone | Anchor + range (anchor radius). 1 s scan after Retreat/Guard (World.FindEnemyIn: on radar, inside the area); not during temp intents. Guard <-> Hunt switch only by priority (MayPreempt, after MinCommitMs); Retreat preempts both. Leash: ship or target past 1.5x radius -> our attack replaced by a move to the area center (Approach, no re-acquire until arrived). Target down -> next in area, else our attack stopped and re-plan. Self-defence fire off while Hunt fights. Saved Guard/Hunt fights resume under their module (Reconcile).
- D10 Formation (Codex): Anchor-link Bool `formation` (default off: profiles saved before it are unchanged; new starters on). Slot = index among local automated ships with formation on and the same anchor, by ordinal ship id; native FollowCommand FollowAngle (anchor-relative, UseWorldRelativeFollowAngle=false, Rotation null so vanilla IsFormation never swaps in an attack), angle PI + 2PI*k/n. A follow without a radius ignores FollowAngle (BaseFollowCommand.GetDestination), so edge = configured or one own diameter, raised until neighbours keep 1.2 diameters (rounded to 50). Re-routes keep the issued follow's parameters (RebuildFollow); routing, stuck and leg checks use the slot point. Not done: explicit OffsetX/Y (no UI), slots shared across MP owners.
- D11 Retreat on damage + repair (Codex): Retreat params `hull` (0.1-0.95, default 0.65) and `repair` (off). Value integrity (not HP) = (Parts.TotalMoneyValue - RepairableParts.GetTotalCostToRepairDamagedParts()) / (Parts.TotalMoneyValue + DestroyedParts.TotalMoneyValue): destroyed parts count, unbuilt drafts don't. Trigger Damage: latch below `hull` (updated each 1 s before stuck recovery), release at min(1, max(0.9, hull+0.05)), persisted (RuntimeRecord.DamageLatch); latched = Retreat owns movement (home at once, escape arc when enemies are near), radar contact alone no longer flees, Guard/Hunt work while unlatched; latched Retreat takes over a self-defence evade, which otherwise stays available under a damage-trigger Retreat.
