# Автофлот: как пользоваться окном

Окно открывается кнопкой на панели или `Ctrl+Alt+A`. Сверху три вкладки: **Назначения**, **Профили**, **Настройки**.
Во «Назначениях» слева дерево флота с галочками, справа — отмеченные корабли: состояние, команды и настройки.

## Быстрый старт

1. **Отметьте корабли** галочками в дереве флота (можно несколько). При открытии окна отмечается текущее выделение
   в игре; дальше отметки меняются только в дереве (или кнопкой «Из выделения игры»).
2. **Назначения → Профиль**: выберите профиль (например, «Шахтёр»).
3. **Назначения → Якорь и цели → «Якорный корабль (следовать за)»**: выберите корабль, за которым ходить.
   Необязательно; нужен, если профиль следует за якорем или зона работы «У якоря».
4. Нажмите **«Начать»** над блоком «Быстрый старт».

Блок «Быстрый старт» вверху вкладки «Назначения» показывает эти четыре шага для отмеченных кораблей:
зелёный — сделано, оранжевый — не хватает обязательного.

## Где что задаётся

**Профили — настраиваем логику. Назначения — руководим флотом:** даём кораблям профили, якорь, цели и место работы,
а команды (Начать / Пауза / Снять и команды модулей профиля) — там же, под состоянием. Ни один параметр логики не
редактируется в двух местах.

| Что | Где |
| --- | --- |
| Профиль корабля | Назначения → Профиль |
| Якорный корабль | Назначения → Якорь и цели (для каждого корабля, общего «флагмана» нет) |
| Куда разгружаться | Назначения → Якорь и цели → «Разгружать в» |
| Где стоит рабочий круг (центр, радиус) | Назначения → Рабочий круг (виден, если профиль работает «в круге») |
| Где добывать (ближайшие / круг / у якоря), порог возврата, реакция на врага, модули, приоритеты | Профили |
| Какие ресурсы собирать и сколько держать на борту | Профили → груз профиля |
| Если якорь пропал, дистанция следования, разгрузка в якорь | Профили → Привязки по умолчанию (действуют сразу на все корабли профиля) |

## Только профиль

Своих настроек у корабля нет: все параметры логики (модули, пороги, груз, привязки по умолчанию) берутся из
его профиля, и любая правка профиля сразу действует на все его корабли. У корабля остаются только назначение:
профиль, якорь, цели, рабочий круг и ручные команды. Нужны другие настройки — сделайте копию профиля
(«Профили» → дублировать) и назначьте её кораблю.

- Старые сохранения: свои настройки кораблей из прошлых версий при загрузке отбрасываются (корабль работает по
  профилю; якорь, цели и круг не меняются). Прежний файл сохраняется рядом как `Autofleet.state.json.overrides.bak`.
- «Указать круг» на карте только ставит круг кораблям, чей профиль работает «в круге»; режим работы задаёт профиль.

## Профили

- Профиль — шаблон поведения. Корабль ссылается на профиль и работает по нему «вживую»: любая правка
  (модули, приоритеты, параметры, груз, привязки по умолчанию, имя) действует на все его корабли сразу,
  без кнопок «применить», ревизий и перезагрузки. Запас в трюме уходит в игру сам, через ~0,5 с после
  последнего клика.
- Профиль, на котором сейчас работают корабли, удалить нельзя: сначала назначьте им другой профиль.
  Не запущенные корабли с этим профилем при удалении переходят на профиль по умолчанию.
  Если профиль корабля не найден (старое сохранение, другой сейв), корабль стоит со статусом
  «профиль не найден», в «Профиль» видно «(нет в библиотеке)»; выберите профиль — и он продолжит.
- Строка модуля: галочка (вкл/выкл) · название · `−` приоритет `+` (большее число — раньше) ·
  когда активен (всегда / если есть якорь / если нет якоря) · `✕` убрать модуль.
- «Добавить модуль в профиль»: в списке только модули, которых в профиле ещё нет.
- Сам якорный корабль в профиле не выбирается: профиль задаёт только «следовать за якорем» и что делать,
  если якорь пропал.

## Дерево флота

- «Все корабли» → папки профилей → корабли; корабли не в автофлоте — в последней папке «Не в автофлоте».
- Галочка есть на каждом уровне: корень и папка отмечают все свои корабли (и свёрнутые тоже); оранжевая галочка —
  отмечена часть, клик по ней отмечает все. Можно отметить весь флот, несколько профилей, профиль и пару кораблей
  из другого — любой набор.
- − / + сворачивает папку, ↑ / ↓ меняет её местами с соседней. Это порядок профилей в библиотеке:
  тот же порядок во вкладке «Профили» (там кнопки «↑ Выше» / «↓ Ниже»), он сохраняется.
- Строка корабля: имя, активный модуль · состояние · трюм % (процент — только если профиль работает с грузом).

## Состояние и команды

- Сверху вниз справа: отмеченные корабли → состояние → команды → «Быстрый старт», профиль, привязки.
- Первый ряд команд есть всегда: «Начать» (для кораблей не в автофлоте), «Пауза / Продолжить», «Снять с автофлота».
- Второй ряд — команды модулей профиля. Сейчас их даёт только «Разгрузка»: «Разгрузиться сейчас» и
  «К точке разгрузки». Профиль без «Разгрузки» (например, охрана) этих кнопок не показывает.
- Если отмечены разные корабли, команда показывается, когда её даёт хоть один профиль; «— 2/5» значит, что
  выполнят её 2 из 5 отмеченных (остальные без модуля или без точки разгрузки, подсказка объясняет).
  Неактивная кнопка показывает подсказку, почему она недоступна.
- Строка состояния: что делает корабль, активный модуль, что его вытеснило, и блокировки
  (например, «зона „у якоря“ требует модуль „Якорь“»). Трюм — только если профиль работает с грузом.
- Изменения применяются ко всем отмеченным; различающиеся значения показаны как «—» или «Разные значения».

## Скоро

Строительство, логистика/экипаж и экономика пока не реализованы; их описание — в «Настройки → Скоро».
